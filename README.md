# reco Model Hub

Fine-tuned RF-DETR models for sports, shared with [Reco Trainer](https://github.com/wendibus/reco-trainer). Use a model as a starting point and fine-tune it on your own images: the trainer measures before and after on your own validation images.

Upload and download happen inside the trainer. Nothing here needs to be done by hand.

## What is in here

- `sports/<sport>/<size>/<model>/model.json`: one folder per model, with nano, small and medium as sizes.
- Weights are release assets, as safetensors. They cannot run code when loaded.
- `index.json` is a release asset of the tag `index`, generated by `publish.yml`. It is what the trainer reads.

**No pictures and no videos, ever.** Neither samples nor training data. A pull request that adds any fails.

## Scores

Scores are the uploader's own statements on the uploader's own images. There is no central benchmark yet, so they are not comparable between models. `training` says what a model was trained on: a model from one hall has only seen one hall.

Whoever publishes a model is responsible for it and confirms the rights to it and to the data it was trained on. Models are provided as they are, without warranty, under the Apache License 2.0. See `LICENSE` and `NOTICE`.

To report a model, open an issue with the "Report a model" template. Reported models get hidden with `"deprecated": true`.

## Review

A maintainer reviews every pull request. Before merging, check that:

- the checks passed and `.github/` and `scripts/` are untouched,
- name and description name no club, player or child,
- `training` looks plausible.
